## Installation

```bash
mkdir Sync_Pure_4TU_WUR
cd Sync_Pure_4TU_WUR

python -m venv .venv
source .venv/bin/activate
```

Create a `requirements.txt`:

```
requests>=2.31
pandas>=2.0
streamlit>=1.30
python-dateutil>=2.8
```

Install dependencies:

```bash
pip install -r requirements.txt
```
